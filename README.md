# Notes+ ᶠᵒʳ ᴾᶜ

A desktop notes app written in Jetpack Compose with many (upcoming) features.

----------

Currently implemented features:
* Notes
* Reminders
* Folders
* Text editor
* Markdown Preview in notes

## Downloads
* [alpha-0.0.2 (stable)](https://github.com/nct32/NotesPlusForPC/releases/tag/alpha-0.0.2)

## We also have an Android app!
* The Desktop app was not built on the base of the Android app, but you can check it out [here](https://github.com/nct32/NotesPlus).


## This app is guaranteed to have bugs in its current state (alpha-0.0.2)
* If any bugs are to be found, please open up an [issue](https://github.com/nct32/NotesPlusForPC/issues) and clearly explain the bug with steps to reproduce the bug.

## Recommended Requirements
* Windows 10 21H1+
* A way to run the installer (no its not virus)
